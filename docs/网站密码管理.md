# 全站统一静态密码

所有访客只看到密码输入框，不能自行注册或配置密码。网站从同源 `site-password.json` 读取同一份加盐校验值，不使用浏览器自定义密码。每次打开、刷新需重新输入；回到已打开页面时重新检查配置是否变化。已打开页面不是实时强制下线。

## 管理员修改

1. 在本机项目目录双击 `配置网站密码.cmd`，保持窗口打开。
2. 浏览器打开 http://127.0.0.1:4188/ 。这个地址仅本机可访问，管理页面不会打包进网站。
3. 输入当前密码、新密码并确认，点击「保存并发布到网站」。
4. 工具使用本机现有 GitHub 登录，校验 main 分支、工作区和远端一致后，只提交密码配置并推送。等待 GitHub Pages 部署成功后生效。
5. 关闭终端停止管理工具。若提示已保存但发布失败，不要再次重设；检查 Git 状态和网络完成提交/推送。

密码不明文保存在配置文件中。遗忘密码时需由具有本机代码/GitHub 写权限的维护者重新生成配置并发布；访客不能通过清空浏览器存储重置全站密码。

这是用户选择的静态页面锁，不是服务端身份验证。静态代码可被绕过，公开校验值可被离线猜测，旧数据接口与浏览器账本未因此得到加密或访问控制。不要以此作为敏感财务资料的安全保护。无需 Cloudflare。
