# 人民币展示换算

- 账户余额表读取「币种」列，空白兼容为 CNY；支持中文币种名及 ISO 代码。原币金额、币种保留在账本和 JSON 备份中，不把换算结果回写为原始金额。
- 有「期间（月）」时只导入最大月份的账户快照，不叠加历史月份。统计日期保留原值。
- 展示时将账户、资产、流水和现金流转换为人民币后再汇总。账户页同时列出外币原始余额。
- 资金预测表是既有人民币口径，不依据账户的新币种列二次换汇。导入预测所需的账户期初回退值使用导入时参考汇率。
- 来源：https://frankfurter.dev/ ，使用 ECB 每日参考汇率。发布脚本读取 CNY 基准报价并取倒数，得到每单位外币对应人民币金额。四舍五入至人民币分；非银行成交报价，不含点差和费用。
- GitHub Pages 工作流每次发布、每日 UTC 18:23 获取汇率。下载失败则停止发布并保留原网站；GitHub 调度可能延迟。页面每次打开读取同源 exchange-rates.json，显示报价日期，超过四天提示可能过期。
- 网络失败且有缓存时显式标注缓存；无可用汇率或未知币种时暂停金额汇总，不将外币默认为人民币。请求仅传递公开币种参数，不发送个人账户信息。
- 已导入的旧记录没有币种来源，不能从名称或备注推断。请重新导入带币种的新工作簿。

验证：`cd web` 后运行 `node tools/update-exchange-rates.mjs`、`pnpm test`。
