# 超级个人页（本地版）

双击“打开个人页”快捷方式，或运行“打开个人页.ps1”，访问 http://127.0.0.1:4190/。

包含九个网站入口，以及 Godot、百度网盘、飞书、Obsidian 四个本机应用入口。配图为本地 SVG 用途示意图，不是网站截图或实时数据。

页面源码在 dist。无需安装依赖；启动器使用本机 Node.js。应用启动位置在 server.mjs 的 apps 白名单中。

服务仅监听 127.0.0.1，应用启动仅接受来自本页的 POST 请求，不能执行任意命令。网页入口在新标签页打开。ArtFlow 需要它自己的服务运行。

GitHub Pages 使用仓库根目录的发布工作流：先构建资产管理，再运行 build-pages.mjs 合并页面。站点首页为超级个人页，资产管理位于 finance.html，保持相同域名与原有资源路径。

线上客户端按钮链接回本机个人页，需要该电脑先运行本地服务；线上不会调用本机启动 API。客户端路径、启动服务和快捷方式仅留在本机，不提交到 GitHub。网页版入口保持直接访问。
